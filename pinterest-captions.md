## Tips for posting on Pinterest

- Upload the PNG file directly (not the SVG)
- Paste the caption in the description box — Pinterest uses the first few lines as the preview
- Paste the hashtags after the caption in the same box
- Set the destination link to the matching page on your site
- Post them one per day over 5 days rather than all at once — Pinterest rewards consistent posting
- Best times to post: evenings (7–9pm) and weekends
